# מסחר יומי למתחילים — מ־0 לתוכנית מסחר ממושמעת

אפליקציית קורס אינטראקטיבית ללימוד עצמי של מסחר יומי למתחילים, בעברית, עם ממשק RTL.
האפליקציה מלמדת את הקורס המלא באופן עצמאי: שיעורים, מבחנים, מחשבונים, יומן מסחר,
בניית תוכנית מסחר ופרויקט גמר — ללא צורך במורה, וידאו חיצוני, ברוקר או קבוצה.

> ⚠️ **לחינוך בלבד.** אין באפליקציה ייעוץ השקעות, איתותי מסחר, או המלצה לקנייה/מכירה.
> מסחר יומי כרוך בסיכון גבוה ורוב המתחילים מפסידים כסף ללא משמעת וניהול סיכונים.

## טכנולוגיות
- Next.js 14 (App Router) + TypeScript + React 18
- Tailwind CSS (RTL, מצב כהה/בהיר)
- שמירת התקדמות מקומית ב-localStorage (ללא שרת, ללא התחברות)

## איך להריץ — שתי דרכים

### דרך 1 (מומלצת): קישור אינטרנט חינמי שעובד בכל מחשב ונייד
האפליקציה מתפרסמת אוטומטית כאתר חינמי דרך **GitHub Pages**, ישירות מה-repo הזה.
מה צריך לעשות פעם אחת:
1. למזג (merge) את הקוד לענף הראשי, או פשוט להשאיר את הענף — ה-workflow רץ אוטומטית.
2. בגיטהאב: **Settings → Pages → Source** → לבחור **GitHub Actions**.
3. להמתין דקה-שתיים שה-workflow בשם "Deploy to GitHub Pages" יסתיים (לשונית **Actions**).
4. הקישור יופיע ב-**Settings → Pages** ויהיה בערך:
   `https://efikatash.github.io/Day-Trading/`

עכשיו אפשר לשלוח את הקישור לבן ולחבר — הוא נפתח בכל דפדפן, במחשב ובנייד, מכל מקום.
אפשר להוסיף אותו למסך הבית בנייד ("הוסף למסך הבית") והוא ייראה כמו אפליקציה.
ההתקדמות נשמרת בכל מכשיר בנפרד.

> אם שינית את שם ה-repo, עדכן את `NEXT_PUBLIC_BASE_PATH` בקובץ
> `.github/workflows/deploy-pages.yml` לשם החדש (למשל `/MyCourse`).

### דרך 2: הרצה מקומית על המחשב (וגישה מהנייד באותו WiFi)
דורש [Node.js 20+](https://nodejs.org). בתיקיית הפרויקט:
```bash
npm install
npm run dev
```
- במחשב: לפתוח `http://localhost:3000`
- בנייד (באותה רשת WiFi): לגלות את כתובת ה-IP של המחשב ולפתוח `http://<כתובת-IP>:3000`
  (במק/לינוקס: `ifconfig` / `ip addr`; בווינדוס: `ipconfig`). למשל `http://192.168.1.20:3000`.
  הנייד עובד רק כל עוד המחשב דולק ומריץ את האפליקציה.

פקודות נוספות:
```bash
npm run build    # בניית פרודקשן
npm run start    # הרצת בנייה (מקומי)
npm run lint     # בדיקת לינט
npm run typecheck
```

## תוכן הקורס
10 מודולים, 63 שיעורים, 10 מבחנים — כולם בעברית עם תוכן חינוכי אמיתי:
1. האמת על מסחר יומי
2. יסודות השוק
3. קריאת גרף למתחילים
4. ניהול סיכונים — הלב של הקורס
5. פסיכולוגיית מסחר
6. אסטרטגיות בסיסיות למתחילים
7. בניית תוכנית מסחר
8. Backtesting ו-Paper Trading
9. מעבר לכסף אמיתי בזהירות
10. פרויקט גמר — תיק סוחר מתחיל

## כלים אינטראקטיביים מובנים בשיעורים
בונה נרות, סימולטור Spread, מיתוס מול מציאות, תרגיל התאמה, תיוג גרף, סימולטור הפסד
יומני, בדיקת מצב רגשי, צ׳קליסט "האם לסחור היום", כרטיסי Setup, תרחישי החלטה,
טבלת Backtest עם Expectancy, מעקב 30 ימי Paper Trading, צ׳קליסט מוכנות וסקירה חודשית.

## ארכיטקטורת תוכן

- `lib/data/lessons/module1..10.ts` — שיעורים + מבחנים
- `lib/data/glossary.ts`, `flashcards.ts`, `scenarios.ts`
